Project: Living Print AR/VR Application

Technologies Used:
- HTML5
- JavaScript
- A-Frame (v1.4.2)
- AR.js (Marker-based AR)

Tools Required:
- Visual Studio Code
- Live Server Extension (VS Code)
- Modern Web Browser (Google Chrome recommended)

Assets:
- 3D Model (.glb)
- Image Marker (.png)
- Video File (.mp4)
- Audio File (.mp3)

System Requirements:
- Webcam-enabled device
- Internet connection (for CDN libraries)


Project Overview:
This project is a Living Print AR/VR application for learning human heart anatomy. The AR page displays a 3D heart model when the Hiro marker is scanned, and the VR page presents the heart in a simple immersive learning scene.

How to Run:
1. Open the project in Visual Studio Code.
2. Start Live Server.
3. Open index.html for AR mode.
4. Open vr.html for VR mode.
5. Allow camera permission for AR mode.
